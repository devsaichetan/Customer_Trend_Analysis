# 🚀 Project Overview

This project analyzes customer purchasing behavior using real-world retail data.

The complete analytics pipeline includes:

- 🧹 Data Cleaning & Preprocessing
- 📈 Exploratory Data Analysis (EDA)
- 🛠️ Feature Engineering
- 🗄️ Data Storage using MySQL
- 📊 Interactive Power BI Dashboard
- 💡 Business Insights & Recommendations

The objective is to identify customer trends, purchasing patterns, category performance, and subscription behavior to support business decision-making.

---

# 🎯 Business Objectives

- Analyze customer purchasing behavior
- Understand revenue distribution across product categories
- Identify high-performing products
- Compare subscribed vs non-subscribed customers
- Analyze sales across age groups
- Study purchase frequency
- Generate business insights through interactive dashboards
